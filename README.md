# TrustTag

**Scan Before You Trust** - A QR-based identity verification platform

## Overview

TrustTag is a modern web platform that helps people verify delivery agents, drivers, couriers, and service providers through secure QR code authentication.

## Features

- **User Registration** - Simple and secure registration for customers
- **Company Registration** - Businesses can manage their service providers
- **QR Code Generation** - Automatically generate unique QR codes
- **Identity Verification** - Verify service providers in real-time
- **Premium Plans** - Access advanced features with subscriptions
- **24/7 Support** - Round-the-clock customer support

## Customization

### Change Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #007bff;
    --secondary-color: #0056b3;
    --accent-color: #28a745;
    --text-color: #333;
    --light-bg: #f8f9fa;
    --border-color: #dee2e6;
}
```

### Update Content
Edit `index.html` to change:
- Text and descriptions
- Pricing details
- Contact information
- Features

### Add More Sections
Simply add new `<section>` elements in `index.html` and style them in `styles.css`.
